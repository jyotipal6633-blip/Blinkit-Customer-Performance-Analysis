# Blinkit Customer Data Analysis | SQL Project

SQL-based analysis of 2,500 Blinkit customer records to understand customer behaviour, order activity, revenue, customer segments, and registration trends.

## Overview

This project analyses Blinkit customer data using MySQL to answer business questions about who the customers are, how they order, and where revenue comes from.

## Dataset

- 2,500 Blinkit customer records
- Fields include customer behaviour, order activity, revenue, customer segments, and registration trends
- Period: Aug 2026

## Tools & Skills

- MySQL, SQL
- Excel
- Data Analysis, Business Analytics, Data Reporting
- Data Cleaning, Aggregation, Customer Segmentation

## SQL Concepts Used

- SELECT, WHERE, GROUP BY, ORDER BY, HAVING
- Aggregate functions: SUM(), COUNT(), AVG()

## Key Findings

- Estimated total revenue of ₹29.03 million
- Regular customers had the highest average order value at ₹639
- Analysed customer segments and average order value
- Identified monthly customer registration trends

## Business Insights

- Customer segmentation helps identify the most valuable customer groups
- Average order value varies by segment, with Regular customers leading
- Registration trends show how the customer base grew over time
- The analysis provides a structured report and presentation to communicate business insights
